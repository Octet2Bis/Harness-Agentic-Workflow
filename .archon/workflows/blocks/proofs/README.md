# Preuves (blocs)

Une preuve par bloc `PROUVÉ` : `<id>.md`, au moins 200 caractères, avec les trois faits de
`MECHANICS.md` § 2 (R3 le vérifie) :

```markdown
# Preuve — <id>

## Contrôles
Chaque règle a refusé un cas mauvais : <fichier .test.ts>, fixture `rejected`.

## Juge
Le juge a refusé un cas mauvais connu : run <id>, le <date>, motif.

## Run réel
Run <id>, le <date>, entrée <…>, livrable <chemin>, vérifié par <qui>.
```

Aucun bloc n'est encore `PROUVÉ` : tout est `VERIFIED` sans modèle (2026-10-18).
